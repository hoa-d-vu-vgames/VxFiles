# VxFiles 2.7.0

This release adds package configuration to Automation Tools and updates the Files Community base to v4.2.9.

## Features

- **Configure Automation Packages from the Tools tab.** A package can expose a Programs page for required executables and one page for each action's settings.
- **See readiness per action.** An action that still needs a program is clearly marked without preventing configured sibling actions from running.
- **Edit typed action settings.** Boolean, integer, number, text, choice, file-path, and folder-path settings use controls suited to their declared type.
- **Use configured values in every input mode.** JSON-input actions receive the run request on standard input, while exact-argument actions keep only selected paths in `argv` and can load the same immutable request from the bundled helper.

## Reliability and security

- A package configuration is validated first and committed as one atomic state-file replacement, so a failed Save cannot leave only part of the dialog applied.
- Package trust now covers every currently configured program used by the package, preventing sibling actions from alternating trust prompts.
- Programs are resolved and fingerprinted again after consent, so an executable changed while the trust dialog is open is refused before the action starts.
- Exact 64-bit integer settings are preserved without passing through floating-point conversion.
- Cancelling while a run request is being prepared is reported as Cancelled instead of Failed.

## Files Community v4.2.9 update

- Incorporates upstream navigation and context-menu performance improvements.
- Includes fixes for opening folder shortcuts, copying text from the rename box, command placement in context menus, and several Properties-window crashes.
- Includes upstream nullable-safety, serialization, and general reliability improvements through Files v4.2.9.

## Installation

Download `VxFilesApp-win-Setup.exe` below. VxFiles installs for the current Windows user without administrator rights. Windows SmartScreen may warn about the unsigned installer.

Existing VxFiles installations will download this update automatically and apply it when VxFiles exits.
